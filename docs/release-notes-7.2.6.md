# LILLA Audio Sampler 7.2.6

## Expanded MIDI Loop recording

Record loops up to **120 seconds** long, with up to **1,000 MIDI events on each of the four tracks**.

Note On and Note Off each count as one event. Recording stops automatically when the duration or event limit is reached. Track 1 sets the loop duration for the other tracks; Tempo adjustment can extend playback beyond the original recording duration.

Existing saved loops remain readable. Loops saved with this release require firmware 7.2.6 or later.
